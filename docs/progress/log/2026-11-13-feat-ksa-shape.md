# 2026-11-13 排水の出口を前澤 KSA（防蟻 KSA-B）の形・高さに（ブランチ `feat/ksa-shape`、main から）
- 依頼: 「このメーカーです」（前澤化成 KSA-B75N×280H の図面 04702164）。前回確認中だった「φ100 の出口の KSA 品番」への答え
- 図から読んだ形: 外の口（基礎の外の面）から内へ水平 255、そこから 45° で土間の口へ（芯で水平 478・高さ 223、管の下から H280）。さや管 φ114・フレキ管 498
- `kisoSleeve.ts`: `KSA_STRAIGHT = 255`、`ksaStandardHeights`（標準 45° の H。50・75 は 230/280、100 は 333。深基礎 90° は自動では使わない）、`ksaExit(d, 土間の口, 目安)`（目安 GL−370・土かぶりより下へ行かない一番深い品。どれも下へ行くなら一番浅い品）
- 排水の出口の形（`drainRoute.exitGeom`）: 土間の口 → 45° → KSA の曲がり（外の面から 255 内・管底 = 土間 − H）→ 基礎を水平に抜ける。外の口が目安（GL−370）より 100 以上高い、または土かぶりが足りなければ、基礎の外の面で真下へ L で落として GL−370 から外へ（「出した時、高さが高ければそこから L で落としてマスにつけます」）。KSA の曲がりはフレキ管が曲がる所なのでエルボに数えない（`fitting: none`）。外周が分からない工事・φ125 以上は従来どおり
- 排水の自動計算（`heights.ts`）: KSA の曲がりを KSA の高さに固定（太さは 45° の管で選ぶ。外の管は自治体の決まりで φ100 に太くなるため）。外の面で落とす形があれば、外の口・落とした下（GL−370）も固定。落とす管の無い形（手で描いた・前の版）は、落とす必要があれば出口ごと GL−370（前と同じ）。`exitOutZ`
- 検査: 基礎の外の面の口（基礎の中の横の管からすぐ落とす所）は土かぶり不足に数えない。積算: KSA の H は 45° の管から（`riseAt`）、太さも 45° の管で選び、同じ出口を 2 つ数えない。防蟻品（KSA-B・KSS-B）を既定に（積算の設定で外せる）
- 変わったこと: 壁に近い便器（芯から 360）は、KSA の土間の口（外の面から 255 + H 内）より壁側になるので、近い北ではなく西の外壁から出す（E2E 図面から 3D の期待値を変更）
- 独立レビュー（Sonnet）: 致命的な不具合なし。指摘で直したもの: 外の起点を勾配の付け直しから外す条件を KSA の外の口だけに狭める・外周が分からない工事では KSA の形にしない・「外で落とさない」場合のテストを追加。変えていないもの: 立上りが 510 を超える太い基礎で曲がりが芯より外に出る件（現場で無い太さ）、給水の 45° 管の H（KSS は縦の立上りで使う）
