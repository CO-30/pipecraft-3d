# 2026-11-13 不具合: 手で置いたヘッダーを「まとめてつなぐ」が使わない（ブランチ `fix/manual-header`、main から）
- 報告: 1 階の図で給水・給湯ヘッダーを置いてから「汚水・水・湯をまとめてつなぐ」を押すと、置いたヘッダーを使わず、別の所（メーターの引込の近く）にヘッダーを置いてそこから配管していた（スクショ 2 枚）
- 原因: `routeSupplies` はヘッダーを「1 階の床下（mountZ < 0）にあるもの」だけ数えていた。1 階の図（床の上）で置いたヘッダーは高さが未設定（床上・標準）なので数えられず、ヘッダーが無いとみなして新しく置いていた（main では枝分かれでつなぎ、置いたヘッダーは使わないまま）
- 修正 `src/model/supplyRoute.ts`:
  - 1 階の床の上に置いたまま・配管がまだ無いヘッダーは、同じ場所の床下（出口 −300）へ下ろして使う。知らせに「1 階に置いてあった〜を、同じ場所の床下へ下ろしてつなぎました」
  - 置いたヘッダーの出口が足りないときに足すヘッダーは、置いたヘッダーのそば（器具の側に横並び）に置く。メーターの近くへは置かない
  - 配管をもうつないである床上のヘッダーは動かさない
