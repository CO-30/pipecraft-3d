# 2026-11-18 fix/hot-header-inlet — 給湯ヘッダーの入口がつながらない（手でつなぐ）を直す

## 症状
実物の図面（木造平屋）で自動でつなぐと、毎回「給湯ヘッダーの入口へ配管をつなげませんでした（手でつないでください）」と出ていた（直す前の main から。公共ますの有無に関係なく）。

## 原因（実物の配置を出して確かめた）
- 給水ヘッダー（3722, 8298）へ入る給水の管が、北の外壁の入口から y=8298 の線を通って給水ヘッダーの入口（3512, 8298）へ入っていた
- そのあと給湯ヘッダーを、給湯の入口のすぐ内側（3037, 8298）に置いた。ちょうどその給水の管の上で、給湯ヘッダーの入口（2887, 8298）へ入る向き（長さの方向）がその管で塞がり、道が見つからなかった
- ヘッダーを置く所は、壁・基礎・ほかのヘッダーとの空きは見ていたが、先に引いた給水・給湯の管は見ていなかった

## 直したこと
- `supplyRoute.ts` `placeHeader`: ヘッダーとその周り・入口の前の箱を、先に引いた給水・給湯の床下の管（ヘッダーの高さの近く）が横切る所には置かない（`segHitsBox`）

## 結果（実物・画面と同じ流れ、手元のみ）
- 給湯ヘッダーは（3037, 7998）に置かれ、入口へつながる。給水・給湯ヘッダーの入口のすぐ先に止水栓（ユーザーの施工どおり）
- 公共ますなし・あり とも: 「つなげませんでした」「見つかりませんでした」の知らせ 0、お湯 3 本・給水 8 本、干渉 0、積算の要確認 0、申請画面の注意 5 件（前と同じ本当の確認事項）
