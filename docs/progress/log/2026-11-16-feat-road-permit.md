# 2026-11-16 feat/road-permit — 道路の手続き（本管からの取出し）

ユーザー要望: 本管からの接続に要る道路使用許可などの書類も自動で作れるように（「痒いところに手が届く」）。方式 C（共通様式を既定、公式様式は自治体ごとに上書き）。与那原町では道路占用の申請者は会社。

## 作ったもの
- 申請図面 →「申請書」タブに「道路の手続き（本管からの取出し）」の欄（どの自治体プロファイルでも出る）
  - 要る手続きのチェックリスト（提出先・出す時期の目安・過ぎていれば赤）: 道路占用許可・道路使用許可・（縁石/側溝をいじるなら）道路工事施行承認・着手届・完了届・占用料の減免・埋設物の確認・穿孔の立会い・公共ます/取付管。私道なら所有者の承諾。掘らないなら「要りません」
  - 気をつけること（未入力・本管の位置が幅員より遠い など）
  - 質問 7 まとまり（道路／給水の取出し／下水の取付管／掘る大きさと戻し方／車や人の通し方／日程／提出先と申請者）
  - 「道路の申請書類一式 (PDF)」: 占用許可申請書・道路使用許可申請書（別記様式第六）・位置図（見取図があれば）・占用平面図・横断図/復旧断面図・交通規制図（3 種）・工程表・占用内訳調書・着手届・完了届
- 既定値: 申請者＝工事店の情報、引込管＝メーター入口の管、下水＝公共汚水マスがあれば「する」、給水と下水の間隔＝メーターと公共ますの距離
- 提出先（道路管理者・警察署）は市町村ごとにこの端末に覚え、次の工事から自動で入る
- 様式の無い自治体（標準など）でも工事店の情報を入れられるようにした
- 入力は `doc.site.application` の `road.*`（スキーマ変更なし）
