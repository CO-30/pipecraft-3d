# 2026-11-27 feat/requestion — 質問に答えた後に図面が変わったら聞き直す（自動開発 4 回目）

指示: 定期作業の優先順 (d)「質問に答えた後に図面が変わったとき（例: 公共ますを後から置いた）の聞き直し」。

## 作ったもの
- 質問に答えて保存するとき、その時点の「図面からのおすすめ」（様式の defaults）を `doc.site.confirmBasis` に一緒に保存（新しい省略可の項目。古い工事はそのまま読める）
- `confirmQuestions(…, { drawn, basis })`: 答えたときのおすすめと、いまの図面からのおすすめが違い、答えもいまのおすすめと違えば「まだ答えていない」に戻す（`changed: { before, now }`、おすすめは いまの図面から）。かっこの全角・半角の違いは同じとみなす
- 聞き直さないもの: 道路を掘るかの質問（図面と関係ない）／記録の無い前の版の答え／答えがもう いまのおすすめと同じもの
- 提出書類一式: 聞き直す質問はたたまずに開き、「⚠ 答えた後に図面が変わりました。前の答えは「…」です。いまの図面からは「…」をおすすめします（前の答えのままでよければ、それを選んでください）」を出す
- 手順ガイドの「確認の質問」の件数も同じ数え方（GuideBar の shinseiCtx）
- 申請書の画面・道路・確認申請書の読み込みなど、ほかの画面で答えを手で変えたときは、その項目の記録を消す（手で決めた答えを聞き直さない。store の updateSite でまとめて）

## 独立レビュー（別エージェント・sonnet）
- Critical なし（全角・半角、保存で聞き直しが消えること、古いデータ、答えを変えるモードは問題なし）
- Important: ほかの画面で手で直すと、古い記録と比べてすぐ聞き直してしまう → updateSite で、値が変わった項目の記録を消す（テスト追加）
- Important: おすすめが無いときに答えた質問（記録は空）は、後でおすすめが出て答えと違えば聞き直す → 意図どおり（例: 浄化槽と答えた後に公共ますを置いた）。テストで明記
- Minor: テスト追加（全角・半角の違い、合っているときは answered のまま）。聞き直すときは新しいおすすめを選んでおく（他の質問と同じ。⚠ と前の答えを出すので、そのまま押す前に気づける）は変えない
