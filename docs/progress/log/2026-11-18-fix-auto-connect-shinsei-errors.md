# 2026-11-18 fix/auto-connect-shinsei-errors — 自動でつなぐ段階で、申請図面の注意（土被りなど）が出ないようにする

依頼: 新築工事の実物の図面（立面・平面・基礎・配置。木造平屋）を読み込んで自動でつなぐと、申請画面で「被り」などのエラーがたくさん出る。エラー自体は正しいが、自動でつなぐ段階で出ないように考えて（器具を増やす・つなぐ）、作業者の手間を減らす。Superpowers・独立監査、捏造や有利にするための操作はしない。マージ・公開まで。

## 再現（手元のみ。図面は bench-data/ に置き、リポジトリに入れない）
- `src/bench/shinsei.bench.test.ts`（新規）: 画面と同じ流れ（新しい工事 → 器具の候補を置く → まとめてつなぐ）をストアで再現し、申請画面の全タブの注意・エラー・排水の注意・積算の要確認を数える。`BENCH_DIR=<フォルダ> npx vitest run src/bench/shinsei.bench.test.ts`（public.json で公共ますを置いた場合も）
- 修正前: 申請画面の注意 **56 件**（ほぼ全部が「土被り −659mm が最小 200mm より少ない」など。縦断図とます表に同じものが出る）

## 根本の原因と直したこと
1. **配置図に公共ますの記号が無く「下水引込へ」とだけ書いてある** → 外の汚水マス 8 個をつながず（公共ますが無いとつながない仕様だった）、床下の本管が入った 1 つのマスだけが系統になり、縦断図がそのマスから**床下の管を地中の管として**描いていた（土被りがマイナス）
   - `drainOutlet.ts`（新規）: 下流端のマス = 印のマス → 「下水引込へ」の文字に近いマス（5m 以内）→ 地面がいちばん低い所 → 家から遠い方。マスに `params.downstream` の印（1 つだけ）
   - `connectYard`: 公共ますが無ければ下流端を決めて印を付け、外の汚水マスをそこまでつなぐ（マスが 1 つならつながない）。あとで公共ますを置くと下流端から公共ますへ
   - `siteRead`・`assemble`・`applySite`: 「下水引込」の文字の位置を読み、公共ますが無ければ近くの汚水マスに印
   - 「公共ますがありません」の排水の注意は残す（本物の公共ますの位置・深さは図面に無いので、作り物で埋めない）。知らせにも「公共汚水マスの位置が分かったら置いてください」と書く
2. **下流端を 3 か所が別々に決めていた**（自動でつなぐ／高さの計算の根＝管底がいちばん低いマス・同じ高さは順不同／申請図面＝名前順の最初のマス）→ 縦断図が逆向きに描かれ逆勾配が 6 区間。印のマスで揃えた（`tree.ts`・`outlets.ts`）
3. **縦断図の本線・枝に床下の管を選んでいた**（いちばん長い枝を本線にしていた）→ `extractRoute`・`branchPoints` に マスの点（`manholeNodes`）を渡すと、マスへ向かう枝だけを本線・枝にする（申請図面・ます表・排水平面図・申請書の表題で共通）
4. **地面が途中で下がる所（CB の段差で約 0.7m）で管が地面から出ていた**（公共ますの手前でまとめて落としていた）→ `heights.ts`: 急な経路では、上から標準の勾配で下ろし、土かぶりが足りなくなるマスの手前のマスで先に落とす（残りは今までどおり手前のマス）。公共ますでない根の深さも途中のマスの地面に合わせる
5. 下流端のすぐ横の床下の出口（KSA）が 56°・77° の曲がり（積算の要確認）になっていた → 先の経路が根へ着いた後に急に直接入る経路は、根に落差を足さずマスの外で L で落とす（先に決めた高さを変えない）。部品の判定（`fittings.ts`）も、マスへ高く着く管は着く高さ（`endZ`。3D・勾配の判定と同じ）で向きを見る

## 結果（実物・画面と同じ流れ）
- 公共ますなし（今回の図面そのまま）: 申請画面の注意 **56 → 5 件**。縦断図・ます表の土被り・逆勾配 0、積算の要確認（配管・部品）0
- 公共ますを置いた場合: 37 → 7 件
- 残したもの（本当の確認事項なので消していない）
  - 水理計算: メーター φ20 と描いていない引込で流速 2.33m/s（上限 2.0）。メーターの口径を上げるのは費用の決定なので自動で変えない（今までどおり「口径の提案」で知らせる）。引込が描かれていない仮定の注意
  - ます表: 入っていないマス 1 個（つながっていない雨水ます。別の系統）
  - 排水の注意: 公共ますがありません・標準の決まり（住所未入力）
  - 公共ますを置いた場合だけ: いちばん上流の空のマス（流れ込む管が無い）で土被り 193mm（11-16 の残りと同じ。下流側の高さとの兼ね合い）
  - 急でない経路（一様な勾配）で途中の地面が下がる所は落差を入れない（注意で知らせる。コメントに記載）
