# 2026-11-12 ⑩ 保存した版との比較 — PR 作成（ブランチ `feat/compare`、main から）
- 依頼: 有料 CAD の取り込み計画の ⑩（Rebro の図面の比較）。「全部まとめて」の 1 つ目
- 設計 `docs/superpowers/specs/2026-11-12-compare-versions-design.md`
- 版: 表示パネルの「🕘 版」で今の状態を版にする（名前・工事ごとに 20 版、端末の IndexedDB の別の表。一覧と中身を分けて一覧では中身を読まない）。下敷きの画像・外壁の写真は版に入れない（戻しても今のまま）。あふれたら自動の「戻す前」から消す
- 比べる（`src/model/compare.ts`）: 同じ ID の管は ID で（口径・管種・長さ・位置。排水の高さは自動計算で変わるので見ない）、ID の消えた管は同じ種類の管がどれだけ覆っているかで（一部なくなった・一部口径が違う も）。器具は ID で（種類と動きは 1 つに）。比べる版は排水を計算し直してから。格子の索引で 1000 区間でも速く、ドラッグ中は前の結果のまま
- 画面: 2D は増えた=緑・なくなった=赤の破線（一部も）・変わった/動いた=だいだい、器具の前の位置は灰の破線。3D は増えた管を光らせ、なくなった管を赤の半透明（選べない）。図の下の帯に数・系統ごとの長さの差・建物の違い・一覧（タップでその階・その物へ）
- 戻す: 2 回押して確定。戻す前を自動で版に残し、元に戻すで取り消せる（排水は版だけで計算し直し、マスを勝手に足さない。隠した要素などの指定は消す）
- 独立レビュー（Opus）: Critical 2・Important 4 → すべて修正・テスト追加（長さの変化・途中を消したのを「違いはありません」と出す、排水の高さの計算し直しで全部「なくなった＋増えた」、1000 区間で遅い・ドラッグ中に毎回比べる、比べていない時も全部描き直す、版が大きい（下敷き）・一覧で全部読む、「申請提出」の版が先に消える）。Minor から 11 件も
- 見送り（Minor）: 比較中の PB の曲げの弧の色
- テスト: 単体 1056 合格、E2E 版の比較・メモ 9 合格（3 端末）。lint 警告は増えていない
