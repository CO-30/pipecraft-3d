# 2026-11-13 床下の排水を φ100 の本管にまとめる（ブランチ `feat/drain-main`、main から）
- 依頼: 全ての器具から近く材料が少ない位置に φ100 の本管を通す。出口は公共マスに近い側（図面で読めなければ道路側）。床下でそれぞれの排水を本管へ（トイレ 75・キッチン 50・洗濯 50・手洗い 40）。自動のマスはいらないものが多いので、本管の出口を元にマスを置く
- `drainMain.ts`（新規）`routeDrainMain`: 出口の外壁 = 公共汚水マスに向いた一番近い外壁（無ければ使う人が置いた汚水マス → 水道メーターの側を道路側とみなす → どれも無ければ一番材料の少ない外壁）。本管はその外壁に直角な 1 本（櫛の形）、壁に沿った位置は器具の位置の中央値の近く（枝の合計 + 本管 + 内部の立上りの貫通 1 か所 300mm 相当が一番少ない所。外壁の角から 600 離す）。枝は本管に直角、外壁に近い器具は L 字。合流点どうし 150 以上離す。枝どうし・本管と交わらない置き方だけ採る。本管の下流の端（土間の口の 200 内）から `routeDrainsOut` で前澤 KSA → 外の汚水マス 1 か所
- 2 回目以降: 新しい器具は前の本管へ直角（はみ出せば L 字）につなぐ。器具の管より細い枝にはつながない。落とした管の真下・引いてある横管と交わらない。雑排水だけの本管にトイレが入ったら、合流点から外のマスまでを汚水にする
- 本管にできないとき（外周が閉じていない・置ける所が無い）は、これまでどおり器具ごとに近い外壁から出す（知らせる）
- 器具の排水の太さは器具の接続口のまま（トイレ 75・キッチン 50・洗濯機 50・洗面台 40。浴槽 40・シャワー 50 は変えていない）
- `routeDrainsOut` に `opts.ends`（つなぐ端）・`opts.wall`（出す外壁）を追加。「まとめてつなぐ」「排水を外の桝までつなぐ（案）」の両方を本管にした
- 独立レビュー（Sonnet）: 致命的な不具合なし。直したもの: 外壁に近い器具の L 字の枝が交わる（合流の順を本管に近い順に・交わる置き方は採らない）、あとから足した器具が細い枝へつながる・つないだ落とし管の真下を通る・引いてある管と交わる、雑排水の本管へのトイレ（汚水に）、内部の立上りの貫通を費用と数に入れる、知らせの空文字。変えていないもの: 2 回目に本管へつなげなかった器具は別の出口になることがある（知らせる）、本管の位置は中央値と器具の位置から選ぶ近似
