# 2026-11-13 排水は 45° で基礎を抜ける・高く着く管は L で落とす・床下より下の基礎を 3D に（ブランチ `feat/drain-45`、main から）
- 依頼（スクショ 3 枚: 基礎伏図 FG1 の断面・3D・前澤「排水管貫通セット」）: 3D は床下から真下に落として L で外へ出しているが、図面や排水管貫通セットのように出してほしい。出したとき高さが高ければ、そこから L で落としてマスにつける。床下より下の基礎も描く
- `drainRoute.ts`（まとめてつなぐ・排水を外へ）: 床下の配管は「土間の口」で終わり、そこから 45° で基礎を抜けて、外周の基礎の外の面で GL−370 の水平になる（`exitGeom`）。自治体の土かぶりが深い・器具の真下に深く落とした所はそれより深く。45° の長さは壁の芯から 450 まで（それより深い外の口は急に下ろす）。置いてあるマスが外の口より浅ければつながない
- `slope.isRiserLike`: 高さの差が平面の長さの 0.9 倍以上の管（45° など）は、高さを勾配で決めない管として扱う
- `drainSolve/heights.ts`: 外の口（外周の基礎の外の面）も「床下から外へ出る所」として GL−370（土かぶり・立て管の上端 −100 も守る）に固定。先に決めたマス（合流・手で管底を入れたマス）へ高く着く管は、標準の勾配のまま、マスの外で L で落とす（管ごとのドロップ `segment.dropEnd`。計算の写し、保存にも残る）。`slope.endZ` は dropEnd も足す
- `dropLegs.ts`・3D: マスへ高く着く管（100mm 以上）は、マスの壁の外で止めて真下へ落とし、マスへ横から入る形で描く（公共ますの手前のドロップも同じ）。積算に「ドロップ（マスの外で L で落とす）90°エルボ」（L 2 個ずつ・落とす管の長さ）
- `building3d.ts`: 床下より下の基礎（設計 GL があるとき）: 外周の立上りを GL−250（根入れ）まで下ろし、その下に厚さ 150・内側へ 300 張り出すベース（FG1 の標準）。立上りとして選べる
- `kisoSleeve.ts`: 45° で基礎を抜ける管は、その管の高さの差（土間まで）を KSA の H にする
- テスト: 単体 1147 合格（新規 `drainExit45.test.ts` 5）。`drainRoute.test.ts` の期待値を新しい形に（外の口は外の面・GL−370、土間の口は 45° の位置）。E2E まとめてつなぐ・図面から 3D・ます表・申請図面・床下・材料表 57 合格（3 端末）
- 独立レビュー（Sonnet）の指摘と対応: ① `isRiserLike` がドロップ込みの高さで判定していて、計算のたびに 45° 扱いが入れ替わるおそれ → 点の高さだけで判定。② 管がつなぎ替わって木から外れた管に古い `dropEnd` が残る → 全部の管を見て消す。③ 浅くて 45° が収まらない（土間の口が基礎の中に入る）出口 → 土間の口から真下へ下ろして水平に抜く（`steep = false`）。④ つなぎ案（drainRoute）と自動計算（heights）で外の口の高さの決め方がずれていた → 同じ式（外の口の地面・土かぶり・土間 −100）に。⑤ KSA の H がマイナスになり得た → 0 で止める。変えていないもの: 自動ドロップのマスに足が複数つく場合の描き分け、endZ の予備の分岐（今の使い方では起きない）
- 追加テスト: もう一度計算しても同じ・不要になった管ごとのドロップは消す（`drainExit45.test.ts` 計 7）。E2E 図面から 3D（planauto）: 浅い出口は真下に下ろしてから抜くので管が 1 本増える（5 → 6）
