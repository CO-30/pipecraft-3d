# 竣工図モード Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans.

**Goal:** 申請図面を実測長で描いた竣工図に切り替える。
**Spec:** docs/superpowers/specs/2026-11-12-as-built-design.md

## Global Constraints
- 排水系のファイル（profileDrawing/profileSheet/network/schema/municipality/slope/drainRoute/underfloorSlope）とストアの commit に触れない。
- 文字は LabelPlacer、noOverlap に追加。PDF の字形は JIS。

## Review Focus
1. 一部だけ実測（按分の概算を含む）→ 追加距離が単調に増え、勾配は区間ごとに正しい
2. 実測が 0 や極端に短い → 勾配の割り算で無限大にしない（実測 > 0 だけ使う。立管は触らない）
3. 印が表題欄・既存の文字と重ならない（全プロファイル・A3 横/A4 縦）
4. 竣工をやめると申請図に完全に戻る（表題・長さ）
5. スマホで実測の一覧が操作欄の中で入れられる
