# 建物スケッチ入力（実装順1: なぞる → 立体化 → 寸法入力）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 指でなぞった外形から外壁を作り、階数分まとめて立体化し、実測寸法を順番に入れて形を整える。

**Spec:** Claude プロジェクト資料 `claude/建物スケッチ入力と出っ張り継手_仕様.md` の 1・3（実装順1）

## 決定事項

| 項目 | 決定 |
|---|---|
| 寸法未確定 | 壁に `lengthSet?: boolean`（schema v5 に省略可で追加）。`false` = 未確定（「?」表示）。省略・`true` は確定扱い（既存データ互換） |
| 外形の補正 | `straightenOutline`: 間引き → 各辺を水平/垂直に分類 → 同じ向きの連続辺を統合 → 水平辺は y、垂直辺は x を平均して直交多角形を組み直す → 50mm 単位に丸め → 短すぎる辺を除去。始点と終点が離れていても閉じる。直交補正 OFF の時は間引いた多角形をそのまま閉じる |
| 立体化 | 新規作成「なぞって描く」で階数・階高を指定 → 空の階を作る。1階で外形を描くと、壁のない他の階に外壁をコピー（同じ履歴1件） |
| 辺の順番 | 外壁のループを画面上で時計回り、左上の角から |
| 長さの変更 | 軸に平行な辺は「伸ばす側の端より先にある全ての点」（全階の角・部屋の頂点・器具・配管の点）を辺の方向にずらす（直角と平行な辺が保たれる）。斜めの辺はその端の角だけ動かす。固定する側を選べる |
| 確定済みの保護 | 変更で他の確定済みの辺の長さが変わる場合、固定側を反対にして再試行。どちらでも変わるなら拒否し「形が閉じません（○mm ずれ）」を表示 →「実測を採用」で強行し、変わった辺は未確定に戻す |
| 自動計算 | 同じ軸で未確定の辺が1本だけなら、その長さは他から決まる → 「自動計算」として表示し、そのまま確定できる |
| 積算 | 未確定の壁がある現場は積算画面に「寸法未確定の壁があります（数量は仮）」 |
