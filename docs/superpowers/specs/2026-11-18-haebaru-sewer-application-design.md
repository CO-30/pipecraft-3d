## 実物から読み取った書き方（→ 対応）
### 縦断面図
- 公共汚水ますの管底を ±0、高さは m で 3 桁。表は 地盤高・土かぶり・管底高 の 3 行。区間は「100VU / 2.1/100 / 5.30」の 3 行 → 既存（沖縄市と同じ）
- 下流（公共ます）を左、縮尺の矢印「S=1/300」を縦・横に → 縮尺を 1/300 に
- ますの名前は斜め（約 30°）の引出線の先に「NO.1小口径桝 内径150深410」、公共は「既設公共桝内径250 深1100」、落差ますは「深520-1035」（流入-流出） → 新しい書き方（斜めの引出線・内径・深）
- GL の段差は段のところに「(+900)」、左端に「(±0)」だけ（ますごとには書かない） → 新しい書き方
- 図名は「立面図・縦断面図（展開図）」、凡例は箱（既設管 青・新設管 赤・町下水道管 黒）と「※単位はmm 管長はm」、表題欄は 申請地・申請者（○○ 邸）・指定工事店 → 対応
- 実物の「土かぶり」の行は、公共ます以外が管底高と同じ値（写し間違い）。アプリは 地盤高 −（管底高＋管の外径）で正しく計算する（変えない）
- DL（基準線）の数値は書かない
### 配管立図（アイソメ）
- ますは「① H=410」（丸数字＋深さ）、落差は「H=600-1280」、公共は「既設公共汚水桝 H=1100」
- ます間の本管は「VU100×1.6」、器具からの枝は「1.2」と「VU50」の 2 段 → 対応（ますどうしの区間だけ 1 行）
### 平面図（アプリに無かった）

## 方式（検討した 3 つ）
