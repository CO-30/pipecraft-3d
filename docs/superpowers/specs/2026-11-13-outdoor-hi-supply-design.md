# 外回りの給水・給湯を実際の施工に合わせる ほか（2026-11-13）

## ユーザーの要望（要旨）
1. 自動つなぎ: メーターから給湯器の近くまで GL 以下を HI で持っていく（壁をきれいに這わせなくてよい）。
   - そこから床下へ入れる（入れる所はコーキング）。給湯器へは HI を途中まで立ち上げ → 止水栓 → ベンリカンで接続。
   - お湯の戻り: 給湯器 → ベンリカン → 止水栓 → ポリブテン（PB）で下ろし → L（エルボ）で床下へ（コーキング）。
   - どちらの立上りも φ40 くらいのさや管で保護。立水栓は床下に入れず、GL 以下で外回りの HI に接続。
2. 器具を置いたら、まちがって次々に置かないよう ☝️（選択）に戻し、置いた器具の内容を変えられるようにする。
3. 図面から読み取った壁はロックして、まちがって位置を変えないようにする。

## 決めたこと（聞かずに判断。ユーザーの標準指示による）
### 1. 外回り（`supplyRoute.ts`）
- 外の地中の道は `yardRoute.ts`（屋外の汚水の道と同じ: 直線・L 字・建物の周りを回る・方眼。外壁から 300mm 離す）を共用する。
- 給湯器が建物の外にあるとき、床下への給水の入口は給湯器の入口に近い外壁。給湯器が無い・中にあるときはメーターに近い外壁（これまでどおり）。
- 床下への入れ方: 地中 → 外壁の外（基礎の面から 100mm）で床下の高さまで立ち上げ → 基礎を水平に貫通して床下へ（コーキング）。
  床下の高さが GL より 50mm 以上高くないとき（地中を通ることになる）は、これまでの基礎貫通スリーブ（KSS）の形のまま。
- 給湯器の給水: 地中の HI から給湯器の入口の真下で分岐 → HI を立ち上げ（止水栓の高さ = 入口の 300mm 下、GL+200 以上）→ 止水栓 → ベンリカン（300mm）→ 入口。
- 給湯: 出口 → ベンリカン（300mm 下へ）→ 止水栓 → PB 保温10mm で床下の高さまで下ろす → エルボ（L）→ 水平に基礎を抜けて床下へ（コーキング）。
- 立水栓: 床下に入れない。立水栓の真下（GL−300）から地中で一番近い外の給水管（HI）へチーズで分岐。
- 積算: ベンリカンは管ではなく本数で数える。φ40 さや管は「屋外の給水・給湯の立上り（地上に出ている所、外壁から 1m 以内、立水栓・メーターの口は除く）」の地上部分の長さ。
  コーキングは、地上で外周の基礎を水平に抜けて床下へ入る給水・給湯の所の数。3 つとも基礎貫通スリーブの欄に並べる（単価はあとで入れられる）。
- 「Lソケット」は PB のエルボ（NCE）として数える（図に合わせた部品名）。

### 2. 器具を置いたあと
- 置いたら道具を「選択（☝️）」に戻し、置いた器具を選んだ状態にする（続けて置くときは器具の道具をもう一度押す）。
- 器具の詳細に「種類を変える」（同じ仲間の種類のボタン）。配管がつながっているときは変えない（知らせる）。

### 3. 壁のロック
- 壁に `locked`。図面から読み取った壁は最初からロック。
- ロック中の壁は、角・壁のドラッグ、長さの入力、削除で動かさない（知らせる）。ロックした壁とつながる角も動かさない。
- 壁の詳細に「🔒 位置をロック」の切り替えと「この階の壁をまとめてロック／解除」。

## 見送り
- コーキング材の本数（1 本で何か所か）は現場で違うので「か所」で数える。
- ベンリカンの長さの品番選び（300 で固定。長さは区間を伸ばせば変わる）。
