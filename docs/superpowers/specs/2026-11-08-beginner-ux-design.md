# 初心者向け UI/UX 改善 設計（2026-11-08）

ブランチ: `feat/beginner-ux`（main `af65125` から派生）
依頼: 「Pipecraft 3D 初心者向けUI/UX全面改善プロジェクト」。ユーザー指示により確認なしで自律的に進める（データ破壊・既存機能削除・重大な仕様変更は行わない）。

## 1. 参考にした有料ソフトの操作思想

| 製品 | 取り入れる考え方 |
|---|---|
| plusCAD水道V | ほぼマウスだけで作図。図面に部材を置くと部材リスト→見積へそのまま連動。PDF・スキャン図面の取り込み |
| PlumbingCAD | PDF を取り込み→なぞる→材料表・見積。2D で描くと 3D がすぐ見える |
| Graphisoft MEP Designer | 器具・配管の**接続口から描き始める**と系統・口径・高さを引き継ぐ。既存配管の途中から始めると分岐継手を自動挿入。描画中は案内線を表示 |
| AutoCAD MEP（参考） | 「設備を置く → 配管でつなぐ → 修正 → 集計」という決まった順番を画面と手順書で示す |

PipeCraft 3D は既に「接続口からの描画」「途中からの分岐」「2D/3D 同一データ」「実測長」「積算」を持つ。足りないのは**入口・順番・今やることの案内**であり、今回は機能の作り直しではなく案内と画面構成を直す。

## 2. 初心者が最初の5分で迷う点（重要度順）

調査方法: 新規環境で PC(1400×860) と iPhone 13 エミュレーションを操作し画面を撮影（`test-evidence/ux-before-*.png`）。

### P0 操作を始められない
1. ホームが「新しい現場」「バックアップから読み込み」だけ。何のアプリか、サンプル、使い方がない。
2. 新規作成の「なぞって描く／寸法から作る／白紙から描く」の違いが分からない。図面・写真から始める入口がない（作成後に道具「下敷き」を探す必要）。
3. 作業画面に「次に何をするか」がない。外形→器具→配管→長さ→積算の順番がどこにも示されない。
4. **スマホで下の道具バーがはみ出し、器具・下敷き・戻す・やり直しが画面外**（横スクロールに気づけない）。取り消しができない。
5. 屋上タンク（高置水槽）がない（テスト5）。

### P1 基本操作・配管が分かりにくい
6. 道具9個＋戻す・やり直しが同じ並び。建物用と配管用が混在。
7. 操作説明が図面上部の小さな灰色1行で、スマホでは途中で切れる。
8. 配管の種類・口径・高さが選択欄（ドロップダウン）だけ。色と種類の対応が見えない。
9. 何を選択しているか、選択の解除方法が分かりにくい。
10. スマホの下パネルに「階高」「この階を削除」が常に出る（危険・ノイズ）。
11. 実測長の入力場所（配管を選んで設定パネル）に気づけない。何区間入力済みか分からない。

### P2 レイアウト・視認性
12. PC 左列の表示切替が 10 行×3 択で常時表示され、画面が重い。「配管だけ」「設備だけ」の一発切替がない。
13. スマホのヘッダーで「一覧」「積算」「表示」が縦に折り返す。
14. 積算画面のタブ（数量・部品・単価・見積・要確認）の意味が書かれていない。

### P3 スマホ
13・4・10 を含む。タップ領域、ヘッダーの高さ。

## 3. 改善内容（データ形式は変えない）

### A. ホーム（`HomeScreen`）
- 上部にアプリの説明1行と大きな入口4つ: **新しい工事を作る／サンプル工事を見る／使い方／バックアップから読み込み**。保存済み工事はその下に一覧（従来どおり検索・複製・書き出し・削除）。
- サンプル工事: `src/sample/sample.ts` がコードで建物（2階・外壁・部屋）・水道メーター・屋上タンク・器具・配管（メーター→タンク→器具、分岐あり）を組み立て、通常の保存処理で「サンプル工事（練習用）」として新規保存して開く。何度押しても新しい複製を作るので壊しても良い。
- 用語は「現場」→「工事」（表示文言のみ）。

### B. 新規作成（`NewProjectDialog`）
- 作り方を説明付きカード3つ: **指でなぞって描く（おすすめ）／寸法を入れて作る／図面・写真を取り込む**。3つ目は階だけ作って道具「下敷き」を開く（既存 sketch と同じ空の階）。「白紙から描く」は小さなリンクとして残す。

### C. 作業手順ガイド（新規 `src/model/guide.ts` + `src/ui/GuideBar.tsx`）
- 8工程: ①工事情報 ②図面の取り込み（任意） ③間取り ④設備の配置 ⑤配管ルート ⑥配管の長さ（任意） ⑦材料の集計 ⑧見積もり。
- 完了判定は共通ストアの doc から純関数 `guideSteps(doc)` で出す（保存データに状態を持たない）。
  - ②: 下敷きあり／③: 壁あり／④: 器具あり／⑤: 区間あり／⑥: 実測長のある区間数/全区間（任意）／⑦⑧: ⑤が済めば開ける。
- 画面上部（図面の上）に1行: 「ステップ 3/8 間取り — 建物の外周を指で1周なぞります」＋「この作業をする」ボタン（該当の道具を開く／積算を開く）。タップで8工程の一覧を開き、どの工程へも移れる（経験者は自由に操作可）。
- 「ガイドを隠す」で畳める（端末の設定 `prefs.guideHidden`、既存 prefs に追加）。

### D. 道具バー（`Toolbar`）
- 常に見えるもの: **選択／建物▾／器具／配管／戻す／やり直し**（スマホでも6個で収まる）。
- 「建物▾」を押すと上に小さな行: 外形・壁・部屋・ドア・窓・下敷き。建物系の道具が選ばれている間は「建物」ボタンが選択状態で、アイコンも選択中の道具に変わる。
- 既存の `data-testid="tool-*"` は維持（サブ行が開いていない時も DOM に残すのではなく、`setTool` を呼ぶ E2E は建物ボタン経由に直す）。

### E. 操作の案内
- 図面上部の小さな説明を廃止し、図面の左上にカード形の「いまの操作」案内（折り返し可、タップで閉じる）。
- 壁が1つもない時は図面中央に大きな案内（外形を描く／図面を取り込む／寸法から作る）。

### F. 配管の設定
- 種類を色付きボタン（給水=青・給湯=赤・排水=茶・汚水=灰・通気…）で選択。よく使う5種＋「その他▾」。既存の select はその他として残す。
- 描き方の3行説明: ①器具の丸（接続口）か既存の配管から指でなぞる ②曲がり角は自動で直角 ③途中から始めると分岐。

### G. 選択の明示
- 設定パネル上部に「選択中: ○○」の帯と「✕ 選択をやめる」。削除ボタンは帯の右に統一位置。
- 配管区間には「📏 実測長を入れる」を目立たせる（既存 MeasureFields へスクロール・フォーカス）。

### H. 表示切替
- 「すべて／建物だけ／配管だけ／設備だけ」のプリセットを先頭に。詳細（10行）は「詳しく」で開く。

### I. スマホ
- ヘッダーを1行に（‹ 戻る・工事名・保存状態の点・積算・表示）、文字の折り返し禁止。
- 下パネルの階設定（階高・この階を削除）は「階の設定」を押した時だけ。

### J. 積算画面
- 各タブの1行説明（数量＝配管の長さと本数、部品＝継手・器具の数、単価＝値段の設定、見積＝金額、要確認＝自動で決められなかった所）。
- 数量の「根拠」表示は既存（実測/図面）を維持し、凡例を追加。

### K. 器具
- 「屋上タンク（高置水槽）」: 入口（給水 φ25・上部）／出口（給水 φ25・下部）、バルブ用ソケット。schema の enum に追加（古いデータはそのまま読める。新しいデータを古い版で開くと読めない点は既知の制限として記録）。
- 器具の並びに見出し（水まわり・水栓・タンク/メーター・設備・電気）。

## 4. 変えないもの
- 保存データの形式（schema v5）、ストアの操作、積算計算、2D/3D 描画ロジック。
- 既存の道具・機能は全て残す（入口の位置が変わるだけ）。

## 5. テスト
- 単体: `guideSteps`（各工程の完了判定）、サンプル工事の生成（検証済み・器具/配管/分岐を含む・積算で数量が出る）、屋上タンクの接続口。
- E2E（PC/iPhone/Android エミュ）: 依頼書のテスト1〜13 を初心者の操作（ガイドのボタン経由）でなぞる `e2e/beginner.spec.ts`。既存 E2E は道具の入口変更に合わせて最小限修正し、全件合格を確認。
- 画面の撮影（改善前/後）を `test-evidence/` に保存。
- 独立レビュー（別エージェント）。
