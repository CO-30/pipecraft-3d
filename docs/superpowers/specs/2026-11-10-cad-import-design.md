# 図面取り込み（Jw_cad／PDF）を「新しい工事」から — 設計と計画（2026-11-10）

## 目的（ユーザーと担当者の決定）
新築の現場では会社から図面（PDF・Jw_cad）が届く。その図面を「新しい工事」で読み込み、**下絵として敷いて上から配管を描く**（担当者の回答: ①下絵 / 図面は PDF と Jw_cad の両方 / DXF で出せるかは不明）。
壁・部屋・器具の自動認識は今回の対象外。

## 現状
- 下敷き（写真・PDF・航空写真、2点で縮尺）は Phase 5 で実装済み。
- 「新しい工事 → 間取り図を取り込む」は下敷きツールを開くだけで、ファイルはその後に選ぶ。
- Jw_cad（.jww）は読めない。

## 決めたこと
1. **.jww を下敷きにする。** 解析は `ezjww`（MIT、Rust→WebAssembly、0.7.11 固定）。端末内だけで処理し、通信しない。費用ゼロ。
2. **縮尺は自動。** JWW の座標は用紙上の mm、レイヤグループごとに縮尺を持つ。図形が最も多いグループの縮尺を採用し、`mmPerPx = 用紙mm/px × 縮尺` で「縮尺確定済み」として置く。違う縮尺が混ざる場合は知らせ、「2点で縮尺」で直せる。
3. **線画の PNG として保存**（既存の `Underlay` をそのまま使う。`kind: 'image'`）。保存形式（schema）は変えない＝他の作業中ブランチ（PR #21）と競合しない。図形の範囲で切り出し、長辺 4000px（大きすぎれば縮小）。
4. **対象図形:** 線、円・円弧・楕円、文字、寸法、ブロック（入れ子8段まで）。補助線（線種9）、非表示レイヤ、塗り（ソリッド）、点、画像は描かない。
5. **新しい工事ダイアログでファイルを選べる。**「図面を取り込む」を選ぶとファイル欄（PDF・Jw_cad・写真）が出る。作成後に自動で下敷きになる（PDF が複数ページならページ選択）。ファイル無しでも作成でき、従来どおり後から選べる。
6. 下敷きパネルに「📐 Jw_cad図面」ボタンを追加。
7. .jwc / .jws / .dxf は今回対象外（.jwc を選ぶと「.jww で保存し直してください」と案内）。

## 構成
| ファイル | 役割 |
| --- | --- |
| `src/model/cadDrawing.ts` | 純粋関数。解析結果 → 線分と文字（用紙mm）、範囲、採用縮尺、注意 |
| `src/import/cadRender.ts` | 線分と文字を canvas に描いて PNG にする |
| `src/import/jww.ts` / `jww.worker.ts` | Web Worker で WASM を読み込み .jww を解析（画面を止めない） |
| `src/import/pending.ts` | 新しい工事で選んだファイルを下敷きパネルへ渡す |
| `src/ui/UnderlayPanel.tsx` | ファイル種別の振り分け、Jw_cad ボタン、渡されたファイルの自動取り込み |
| `src/ui/NewProjectDialog.tsx` / `src/App.tsx` | ファイル欄と受け渡し |
| `vite.config.ts` | `.wasm` をオフライン用キャッシュに含める |

## テスト
- 単体: 変換（線・円弧・文字・寸法・ブロック・非表示・補助線・縮尺の選び方・範囲）、描画命令、`ezjww` で作った .jww の往復。
- E2E（3端末）: 下敷きパネルから .jww を取り込み縮尺確定済みになる／新しい工事でファイルを選ぶと自動で下敷きになる。

## 計画
1. `cadDrawing`（テスト→実装） 2. `cadRender` 3. Worker 読み込み 4. UI 5. E2E・全テスト・ビルド 6. 独立レビュー→修正 7. PR（main へのマージはユーザー指示後）

## 既知の制限
- 文字は端末のフォントで描くため、幅が元図面と少し違う。
- 線の色・太さ・線種は再現しない（すべて黒の実線）。
- 縮尺の違う図が1枚に混ざる図面は、採用した縮尺以外の部分の寸法が合わない。
