# ⑤ 干渉の一覧・スリーブ表 設計

ロードマップ ⑤（Rebro・Tfas の干渉検査、スリーブ自動挿入・スリーブ表）。

## 目的
- **干渉**: 配管どうしが 3D で重なっている所を見つけ、積算の「要確認」に出す（タップでその区間へ移動。既存の仕組み）。梁・軒・バルコニーとのぶつかりは既に「要確認」にある
- **スリーブ表**: 配管が構造を通る所（基礎の立上り・梁の貫通・外壁・間仕切壁・2 階以上の床・基礎スラブ）を全部拾い、階ごとの**位置図（番号）＋表**を申請画面の「スリーブ表」で PDF に出す。施工前の墨出し・構造の確認に使う

## 決定
- 干渉: 区間どうしの 3D の最短距離 < 外径の半分の和（`outerDiameter`）。端点を共有する区間・同じ点でつながる区間は除く。重なり量（mm）と場所を出す。AABB で絞る
- スリーブの径（一般値。表に注記）: 管の外径＋30mm 以上の内径を持つ、いちばん小さい呼び径（50・65・75・100・125・150・200・250・300）。給湯は保温材の分としてさらに＋20mm（VU100 → φ150。レビューで食い違いを指摘され、一般的な組み合わせに合う＋30 に決めた）
- 部位の拾い方: 基礎の立上り（部材 footing の箱を通る）／梁など（貫通の印のある部材）／壁（その階の高さで壁の中心線をまたぐ。外壁・間仕切壁）／床（2 階以上の床面の高さをまたぐ）／基礎スラブ（`foundation.slabTop` をまたぐ）。1 階の床板は拾わない
- 位置: 建物の左下の角からの X・Y（m）と、その階の床からの高さ（FL±）。位置図に番号の丸を LabelPlacer で置く
- 用紙: A4 横。左に階の平面（壁・部材・配管・番号）、右に表（No・部位・管・スリーブ・高さ）。行があふれたら同じ階の続きのページ
- 保存形式は変えない。排水系のファイルとストアの commit に触れない（estimate.ts に要確認の種類を足すだけ）

## しないこと
- スリーブの自動挿入（部材として置く）、梁の貫通できる範囲の判定（構造の資料が無い）
