# 器具の形をリアルに（2D の平面の記号・3D の部品）設計

依頼（2026-11-12）:「2D、3D の器具の形ももうちょっとリアルにして欲しい」

## 決定
- 器具の種類ごとに、外形の寸法（w・d・h）に合わせて伸び縮みする部品の組み合わせを `src/model/fixtureShapes.ts` に持つ（純粋なデータ。テストできる）
  - `planSymbol(type, w, d)`: 平面の記号（四角・角丸・楕円・線）。例: トイレ＝奥にタンク・手前に便器と便座、洗面台＝カウンターとボウルと水栓、キッチン＝シンク・水栓・3 口コンロ、浴槽＝二重の角丸と排水口、シャワー＝トレイと排水口と水栓、洗濯機＝ふた、ヘッダー＝管と出口
  - `fixtureParts(type, w, d, h)`: 3D の部品（箱・円柱・楕円柱・球）と材質（陶器・天板・木の扉・金物・樹脂・濃い色・水色・ガラス・コンクリート）
- ローカル座標: x 右、y 奥（+y が壁の側。接続口の dy と同じ）、z は設置面から上。回転は図面と同じ
- 外形の四角（当たり判定・選択の枠）・接続口・寸法は変えない。2D は外形の上に記号を重ね、名前は白い縁取りで小さく
- 3D は器具を group にして部品を並べる。選ぶと全部品が光る、半透明（ゴースト）も全部品に効く。マスは円柱・角柱のままで、ふたを付ける
- 器具の高さはカウンター・トレイの高さ。その上の水栓・シャワーのヘッドだけ上に出てよい
