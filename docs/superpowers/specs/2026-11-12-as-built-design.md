# ④ 竣工図モード 設計

ロードマップ ④（水匠NX申請の「計測値の入力で竣工図へ自動変更」）。

## 目的
工事が終わったら、申請画面で「竣工図にする」を入れるだけで、同じ配管データから竣工図を出す。
- 図の長さは**現場の実測長**（区間の `measuredLength`）を使う。実測が無い区間は図面の長さで描き、画面で「未実測 n 区間」と知らせる
- 表題を竣工図に（例「排水設備 縦断図」→「排水設備 竣工図（縦断図）」）、用紙の右上に赤枠の「竣工図／竣工 年月日」の印
- 実測長はその場でまとめて入れられる（図に出ている区間の一覧。図面の長さを横に出す）

## 決定
- 設定は `site.application` の `shunko.on`（'1'）・`shunko.date`（YYYY-MM-DD、既定は今日）。保存形式は変えない
- 縦断図は `profileDrawing.ts`・`profileSheet.ts` に触れず、できたモデル（ProfileModel）を差し替える（`applyMeasuredToProfile`）: 区間の延長＝実測、追加距離を積み直し、勾配＝落差÷実測（逆勾配は「逆勾配」）。立管（長さ 1mm 未満）は触らない
- 展開図（`isometric.ts`）は「長さの関数」を受け取れるようにする（既定は今の幾何の長さ）
- 立面図（riser）は長さを書かないので表題と印だけ
- 印は LabelPlacer で用紙の上側の空いた所に置く（文字の重なり 0。noOverlap に追加）
- 水理計算書・見取図・申請書の様式は対象外（実測長は水理計算にもともと使われている）
- 実測長を図面・モデルの値で上書きしない（読むだけ。入力は既存の `setSegmentMeasured`）
