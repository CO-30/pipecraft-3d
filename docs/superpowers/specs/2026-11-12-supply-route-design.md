# 給水・給湯を床下でつなぐ（案）— 設計（2026-11-12）

全体計画 `2026-11-12-paid-cad-roadmap.md` の PR2（Rebro のルーティングの給水・給湯版）。PR #53（水理計算書）の上に積む。

## 目的
器具を置いたら、ボタン 1 つで「メーター → 床下の給水ヘッダー → 各器具」「給湯器 → 床下の給湯ヘッダー → 各器具」のヘッダー工法の配管案ができる。基礎の立上りは人通口などの切れ目を通って避け、PB は曲げ配管（既存）。できた案の水理計算の判定もすぐ知らせる。

## 決めたこと（ユーザーの方針から）
- **ヘッダー工法**: 給水・給湯とも床下にヘッダー（「給水ヘッダーは床下にも置く」）。床下のヘッダーがあればそれを使い、無ければ置く（設置面 −400＝出口が床から −300）。出口（給水 6・給湯 4）が足りなければ隣にもう 1 台置き、同じ引込から分ける
- **高さ**: 床下の配管は 1 階の床から −300（既存の床下の作図の高さ）。器具の給水・給湯口から真下へ立て管（給水・給湯だけ。排水は落とさない）
- **引込**: メーターの出口 → 地中（GL から埋設深さ。標準 300、宜野湾市 600 ✅ 規程第7条）→ メーターにいちばん近い外壁の外 → 床下の高さへ立ち上げ → 外周の基礎を直角に 1 回貫通 → 床下 → 給水ヘッダー
- **給湯器**: 建物の外（外壁ぎわ）なら、給水ヘッダーの出口 → 床下 → 外周の基礎を貫通 → 外で立ち上げて給湯器の入口。給湯器の出口 → 下ろして基礎を貫通 → 床下 → 給湯ヘッダー。建物の中なら真下へ下ろしてつなぐ
- **ルート**: 既存の `findFloorRoute`（方眼・曲がりは 400mm の遠回り扱い・内部の立上りの貫通は 8000mm 扱い）。先に引いた給水・給湯の管には重ねない（40mm 離す＝方眼 100mm で並べて通す）
- **管種**: 既存の `assignAutoMaterials`（屋内 PB 保温・屋外 HIVP/HTVP、外周をまたぐ所で分ける）
- **何度押しても増えない**: つながっていない給水・給湯口だけをつなぐ。1 回の取り消しで戻る
- **対象外**: 屋外の水栓（立水栓など）・2 階以上の器具はつながない（知らせる）。メーターが無ければ何もしない

## 排水チャットとの衝突
`drainRoute.ts` の中の床下の形の判定（壁・立上り・建物の中）は外へ出ていないので、同じ考え方の小さな写しを新しいファイルに持つ（両方の作業が入ったら共通化する）。触らないファイルは全体計画のとおり。ストアは新しい操作を足すだけ。画面は「器具の真下に配管を落とす」の欄にボタンを 1 つ足すだけ。

## テスト
- 外にメーター、内部に人通口のある立上り、器具 3 つ（キッチン・洗面台・トイレ）、外壁ぎわの給湯器: 給水の木（`buildSupplyTree`）に 4 栓（給湯器を含む）、給湯器の出口から各給湯口へつながる、ヘッダーは床下（mountZ −400）、内部の立上りの貫通 0、外周の貫通 3、床下は PB・外は HIVP
- もう一度押しても増えない／床下のヘッダーがあればそれを使う／給水口が 7 つならヘッダー 2 台／メーターが無ければ何もしない
