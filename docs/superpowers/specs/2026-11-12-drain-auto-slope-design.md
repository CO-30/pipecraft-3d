# 排水の高さ・勾配・桝深の自動計算 — 設計

指示: プロジェクト資料「指示_排水勾配の自動計算_2026-11-12.md」「自治体基準_排水チェック条件_2026-11-12.md」。
目標: 描く人は平面でルートを引くだけ。高さ・勾配・桝の深さは入力しなくてよい。

## 1. 分かったこと（既存コード）

## 2. 決めたこと

### 2.1 正しい値の持ち方（有料 CAD と同じ考え方）
- 排水の**正**は「平面ルート＋区間の属性（勾配・管径）＋固定点（ピン）の高さ」。管底高・桝深は計算で出す。
- 区間: `slope`（比率）・`slopePin`（手で固定）・`diameterPin`。点: `zPin`（手で固定した管底高）。マス: `params.invertPin`。
- `pos.z` は**計算結果の写し**として残す（3D・積算・縦断図・保存済みの工事がそのまま動く）。編集のたびに計算し直して上書きし、読み込み時も計算し直すので、保存された z は使わない。
  - 理由: 保存形式を変えずに済み、元に戻せる。z を保存から外すのは、全部が計算結果を読むようになった後でいつでもできる（指示の「保存しない」とは、ここだけ違う。z は保存されるが、どこでも正として使わない）。
- 既存の `slopeLocked` は `slopePin` として読み替える（保存形式の互換）。

### 2.2 計算の順番（純粋関数 `solveDrain(doc, rules) → { doc, issues }`）
1. **系統を作る**: 排水・汚水の区間とマスをグラフにし、公共ます（無ければ一番下流のマス・外の端）を根にした木にする。
2. **管径**: 器具の排水負荷単位を下流へ足し、表から管径を決める。下流ほど太く、細くならない（`diameterPin` は守り、逆転は検査で出す）。
3. **起点**: 根へ向かう経路が基礎の外周の立上りを貫通する所。起点の管底＝土間＋`startAbove`（既定 0）。
4. **上流（床下）**: 起点から器具の真下の点へ、`underfloorSlope` と同じ決まりで上げる（実装済みを使う）。
5. **下流（屋外）**: 公共ますの管底から上流へ勾配で上げる。勾配の既定は自治体の最小勾配より少し上（2.5 参照。急勾配にしない）。
   - 公共ますの管底が分かっている（配置図・手入力）とき、起点の地中の点の土かぶりと両方を満たすよう勾配を割り振る。最小勾配で足りない・最大勾配を超えるときは検査に出す。
   - 起点（床下の土間）と地中の点の差は、基礎の外の立て管で取る。
6. **マス**: 流出の管底＝下流の区間の上端。流入はそれより段差（既定 20mm、自治体ルール）上。合流ますは一番深い流入管に合わせる。落差が大きいときはドロップます。
7. **ピン**: 固定した勾配・高さ・管径は変えず、その前後を合わせる。
8. **検査**: 最小勾配・最大勾配（自治体の値。無ければ流速 1.5m/秒）・最小土かぶり・桝深の上限/下限・管径の逆転・基礎立上りの貫通・床下で基礎天端を超える。それぞれに**直し方の候補**（マスを足す・勾配を緩める/急にする・起点を深くする・管径を上げる）を付け、ワンタップで当てられる関数にする。

### 2.3 いつ計算するか
- 配管・マス・器具・建物・工事の自治体が変わるたび（ストアの `commit` の中で 1 回）。描いた直後に 3D・縦断図が変わる。
- 自動計算を止めるスイッチは置かない（ピンで止める）。現行の「床下は土間から自動で勾配」も `solveDrain` に入ったら外す。

### 2.4 マスの自動配置（`placeManholes`）
- 起点・合流点・曲がり点・公共ますの手前・一定の長さ（自治体ルール: 管径の 120 倍など）ごと。
- 自動で置いたマスは `params.auto`。使う人が動かした・消したものは覚えておき（`site.manholeOverrides`）、自動でもう一度置かない。足した・動かしたら即再計算。

### 2.5 自治体ルール（データ）
資料「自治体基準_排水チェック条件_2026-11-12.md」の値を使う。
- `MunicipalityProfile` に `drainage` を足す。**値ごとに状態（✅ 原文確認／🟡 国の基準・一般値／❓ 未確認）と出典**を持つ:
  - 管径別の最小勾配・最大勾配（未満）、75mm の例外（建物の汚水の一部・延長 3m 以下）
  - 土かぶり（宅地内・私道内）、桝の設置箇所と直線部の間隔（管径の倍数）、桝の内径の下限、桝深の上限、桝内の落差
- 共通の下限（全自治体）: 勾配 1/100 以上（下水道法施行令 第8条 ✅）、直線部の桝は内径の 120 倍以内（標準下水道条例 ✅）、雨水ますの泥だめ 15cm 以上・汚水ますはインバート ✅。
- 那覇市 ✅: 最小/最大勾配 φ100 2/100・10/100未満、φ125 1.7・8.3、φ150 1.5・6.5、φ200 1.2・4.5、φ250 1.0・3.4。宅地内 20cm・私道 45cm。桝は 120 倍以内・内径 15cm 以上。φ75 3/100 は 🟡。桝深の上限・落差（2cm 🟡）は ❓。
- 宜野湾市・豊見城市 ❓: 国の基準＋一般値で動かし、画面と申請書のチェックに「宜野湾市：未確認（問い合わせ先 098-892-4156）」のように出す。
- 未登録の自治体は標準（日本下水道協会の指針）で動かし「この自治体は未確認」。
- **勾配の既定**: 最小勾配より少し上（φ100 → 2.2/100 程度、`defaultMargin`）。最大勾配（自治体の値。無ければ流速 1.5m/秒）を超えたら警告。床下は 2/100（床下が低ければ 1.5/100。ただし自治体の最小勾配は下回らない）。
- ❓ の値で計算した結果は、検査の一覧と申請書のチェックリストに「要確認」と出す。

### 2.6 画面
- 入力欄は出さない。区間・マスをタップした人だけ、勾配・管径・高さを上書きできる（📌 表示、ワンタップで自動に戻す）。
- 区間ごとに勾配（1/○○ と %）・管底高・土かぶりを小さく表示（`labelLayout` で重ねない）。
- 問題は色で示し、直し方の候補をボタンで出す。

### 2.7 縦断図
- `buildProfile` は計算結果の doc を読む（今もそう）。表に土かぶり・管径を必ず入れる。重なり 0 の検査を続ける。

## 3. 分割（PR ごと）
1. ✅ 床下の自動勾配とレベルバンド（`feat/underfloor-slope`）
2. `solveDrain` の核: 系統・起点・上流/下流・マスの段差・ピン・計算の呼び出し（commit・読み込み）・検査（候補の関数つき）
3. 管径の自動決定（排水負荷単位）
4. 自治体の排水ルール（データ・宜野湾/那覇/豊見城・未確認の表示）
5. マスの自動配置
6. 画面: 区間の表示・色・直し方のボタン・ピン
7. 縦断図の仕上げ（表の行・重なり検査）

## 4. テスト（純粋関数・TDD）
一直線／合流あり／両端固定で勾配が足りない／急勾配になりすぎる／ユーザー固定値あり／桝の追加・削除後の再計算／床下の高さが足りない／公共ますが浅い。
