# 道路の手続き書類（本管からの取出し）— 設計

2026-11-16 / ブランチ `feat/road-permit`

## 何のために
本管（水道の配水管・下水道本管）から宅地へ引き込むとき、道路を掘るので、水道・下水道の申請とは別に道路の手続きが要る。
ユーザー（沖縄・与那原町などで施工。**道路占用の申請は会社から出している**）は、これも PipeCraft 3D から自動で作れて「痒いところに手が届く」ことを望んでいる。

道路の手続き（調べた結果）
- 道路占用許可（道路法 32 条）→ 道路管理者。給水管の引込み、下水の取付管、舗装・側溝の復旧を含む
- 道路使用許可（道路交通法 77 条 1 項 1 号）→ 警察署長。様式は全国共通の別記様式第六
- 道路工事施行承認（道路法 24 条）→ 縁石・側溝などの道路そのものをいじるときだけ
- 着手届・完了届、占用料の減免申請（対象かは窓口で確認）、私道なら所有者の承諾
- 添付図: 位置図・平面図（占用・掘削・復旧の範囲と数量）・断面図（仮復旧・本復旧の舗装構成と埋設深さ）・交通規制図・工程表・占用内訳調書・現況写真
- 許可まで 1〜3 週間かかる例が多い

## 目標
1. 「道路の手続き」を質問形式で答えるだけで、**要る手続きのチェックリスト**と**いつまでに出せば間に合うか（目安）**が出る
2. ボタン 1 つで **道路の申請書類一式（1 つの PDF）** が出る。そのまま印刷・提出できる見た目で、文字の重なり 0
3. 入力は少なく: 工事店（会社）の情報・現場名・住所・メーターの口径・工期など、既にあるものは自動で入れる。提出先は町ごとにこの端末が覚えて次から自動で入る
4. どの自治体プロファイルでも使える（沖縄市以外でも）

## やらないこと（非目標）
- 役所・警察へのオンライン申請の送信
- 自治体独自の公式様式（Excel/PDF）への差し込み — 方式 C の「上書き」側。今回は仕組み（様式セットの差し替え口）だけ残し、様式が届いたら足す
- 道路の正確な形の作図（道路の線は工事データに無い）。平面図・交通規制図は寸法入りの模式図

## 失敗とみなすもの（アンチゴール）
- 文字が重なる・はみ出す図面
- 調べていない窓口名・手数料・期間を「正しい値」として載せる（目安・要確認は必ずそう書く）
- 既存の申請書（沖縄市の給水 Excel・下水 PDF）を壊す

## 方式（検討した案）
- A: 自治体の公式様式に差し込む — 様式そのままだが、自治体ごとに座標合わせが要る
- B: アプリで共通様式を描く — すぐ全国で使えるが、独自様式の自治体には合わないことがある
- **C（採用・ユーザー選択）: B を既定にし、公式様式がある自治体だけ A で上書き**。今回は B を作り、上書きの差し替え口（`ROAD_FORM_OVERRIDES`、空）を用意

## 決めたこと（ユーザー）
- 方式 C
- 与那原町では道路占用の申請者は会社（工事店）→ 申請者欄の既定は工事店の情報

## 設計（Claude の判断）

### データ
- 入力値は既存の `doc.site.application`（文字列の辞書）に `road.` で始まるキーで入れる。スキーマ変更なし・保存/バックアップにそのまま入る
- 項目の定義は `src/road/fields.ts`（`FormField[]` と同じ形）。画面はこの定義から作る
- 提出先（道路管理者・警察署）は端末の設定 `roadOffices`（市町村名 → { roadAdmin, police }）に覚える。現場の値が空なら、住所の市町村で覚えた値を入れる

主な項目（グループ = 質問）
- 道路: 道路の種類（町道・市道・村道・県道・国道・私道）、路線名、幅員(m)、歩道の有無、舗装（アスファルト・コンクリート・未舗装）、側溝や縁石を壊すか
- 給水の取出し: する/しない、本管の管種・口径、本管の位置（官民境界からの距離 m）、本管の土かぶり、引込管の管種・口径（既定: メーター入口の管）、埋設深さ
- 下水の取付管: する/しない、本管の管種・口径、本管の位置、深さ、取付管の口径（既定 150）、給水との間隔（既定: メーターと公共汚水マスの距離）
- 掘る・戻す: 掘削幅（既定 0.6 m）、復旧の余裕幅（既定 0）、仮復旧・本復旧の舗装構成（舗装の種類から既定。例 As 50・粒調砕石 150・再生砕石 …、編集可）
- 交通: 規制方法（片側交互通行・路肩規制・通行止め）、交通誘導員の人数、作業時間
- 日程: 着工日・完了日、各作業の日数（準備・掘削・分岐・埋戻し・仮復旧・本復旧）
- 提出先・申請者: 道路管理者（宛名）、警察署、占用期間、現場責任者・携帯（既定: 主任技術者）

### 計算（純関数 `src/road/model.ts`）
- 取出しごとに: 道路内の延長 = 本管の位置、掘削面積 = 延長 × 掘削幅、復旧面積 = (延長 + 2×余裕) × (幅 + 2×余裕)、掘削深さ = 埋設深さ（と本管の深さの深い方）
- `roadChecklist(values)`: 要る手続き・届・確認事項の一覧（窓口の種類、アプリで作れるか、出す時期の目安）
- 期限の目安: 着工日 − 目安日数（占用 21 日・使用 7 日。画面で「目安」と明示、値は設定で変えられる）。今日を過ぎていたら赤で知らせる
- 未入力・矛盾の注意: 本管の位置が幅員より大きい、深さが未入力、着工日が無い など

### 書類一式（`src/road/sheets.ts`、全部 `Sheet` で描き `sheetsToPdf` で 1 つの PDF）
1. 道路占用許可申請書（A4 縦。国の様式の項目: 占用の目的・場所・物件・期間・構造・工事期間・工事方法・復旧方法・添付書類）
2. 道路使用許可申請書（A4 縦。別記様式第六の項目）
3. 位置図（既存の見取図。地図が取れないときは入れずに知らせる）
4. 占用平面図（A4 横。道路の帯・官民境界・本管・引込管・掘削範囲、寸法と数量の表）
5. 横断図・復旧断面図（A4 横。道路の断面に本管・引込管・深さ、仮復旧/本復旧の層の図）
6. 交通規制図（A4 横。規制方法ごとのひな形にコーン・看板・誘導員・工事区間と凡例）
7. 工程表（A4 横。作業ごとの棒）
8. 占用内訳調書（A4 縦。物件・口径・外径・延長・面積）
9. 着手届・完了届（A4 縦 2 枚）
- 文字は `labelLayout`（fitText・spread1D 等）で置く。全部を `noOverlap.test.ts` に加えて重なり 0
- フォントに無い文字は既存どおり置き換えて知らせる

### 画面
- 申請図面の「申請書」タブに「🚧 道路の手続き（本管からの取出し）」の欄を足す。様式が無い自治体（沖縄市以外）でもこの欄は出す
- 上から: チェックリストと期限 → 質問（グループごと、初めての人にも分かる言葉と補足）→「道路の申請書類一式 (PDF)」ボタン
- スマホで使える幅（既存の `shinsei-forms` の並びに合わせる）

## 作り手に任せること
- 図の細かい寸法・配置、目安日数の既定値の微調整、外径の表（VP/HI/PE/VU の代表値）
