# ⑨ 図面・3D にメモ — 設計（2026-11-12）

有料 CAD の取り込み計画の ⑨（Tfas・Rebro のマークアップ・コメント／BCF にあたるもの）。

## 目的
- 現場への指示・確認事項（「ここは梁を避ける」「メーター位置は施主に確認」など）を、図面と 3D の **その場所** に残して伝える。
- 仕事中はスマホだけで使うので、スマホで置く・読む・直す・済にする・一覧を LINE などへ送る、がすぐできること。

## 決めたこと（ユーザーに聞かずに判断）
- **2 通りの置き方**
  1. 道具「📝 メモ」で平面図をタップ → その場所にメモ。配管・器具・接続口の上をタップしたらそれに **付ける**。
  2. 何かを選んでいるとき（2D・3D どちらでも）、選択中の帯の「📝 メモ」→ 選んだものに付ける。3D からはこちらで置く（3D の面をタップして場所を決める方式は当て方が難しいので見送り）。
- 置いたら道具は「選択」に戻り、メモを選んだ状態で文字の入力欄にすぐ入れる（続けて誤って置かない）。
- **付けたメモは付けた先について動く**: 配管・器具・接続口を動かすと、同じ履歴の中でメモの位置もそろえる（`syncNotes`）。区間を分けた（バルブ・分岐・切断）ときは、メモの位置を通る新しい区間に付け直す。付けた先が消えたら最後の位置に残し「付けた先は消えています」と出す。
- 壁・部屋・梁などに付けたメモは、置いた位置のまま（建物は動かす機会が少ない。付けた先の名前と「選ぶ」は使える）。
- **高さ**: 付けたメモは付けた先の高さ。付けていないメモは高さを持たず、3D では階の床 ＋1200mm（床下の図で置いたものは床 −300mm）に出す。階の高さを変えても追従する。
- 番号は置いた順（全階通し）。消したら詰める。
- 済（対応済み）にできる。済は灰色・✓。一覧は「未対応だけ」に絞れる。
- 表示: 2D はピン（黄色の丸に番号）。選んだメモは吹き出しで本文。今の階のメモだけ出し、床下の図／床上の図で範囲外のものは薄く。3D は番号の札（いつも手前に見える）、タップで選べる。表示パネルに「メモ 表示/非表示」。
- 一覧（表示パネルの下・スマホは表示のシート）: 番号・階・付けた先・本文の 1 行目・済。タップでその階へ移ってメモを選ぶ。「📋 文字でコピー」（スマホは共有シート）で工事名と一覧を文字にする。
- 保存: 工事のデータに `notes`（省略可。v5 の途中で足した `elevations`・`site` と同じ扱いで、保存形式の版は上げない）。書き出し JSON にも入る。元に戻す・やり直しの対象。
- 申請図面・DXF・PDF には **出さない**（社内の指示。提出物に混ざらないように）。

## データ
```ts
note = {
  id, floorId,
  x, y,                 // 平面の位置 mm
  z?,                   // 付けた先がある時だけ（付けた先の高さ）
  under?: boolean,      // 床下の図で置いた（付けていない時の 3D の高さ）
  text: string,         // 1000 字まで
  done?: boolean,
  target?: { kind: 'segment' | 'fixture' | 'node' | 'wall' | 'room' | 'opening' | 'member' | 'corner', id },
  createdAt, updatedAt?
}
```

## 部品
- `src/model/notes.ts`（純粋な関数・単体テスト）: `notePlaceFor`（選択→位置・付けた先）、`syncNotes`（付けた先へ位置をそろえる・分けた区間へ付け直す）、`noteNumbers`、`noteTargetLabel`、`notesText`（コピー用の文字）、`notesOnFloorRemoved`。
- `src/model/schema.ts`: `noteSchema` と `projectSchema.notes`（省略可）。
- `src/state/store.ts`: `addNote`・`addNoteFromSelection`・`updateNote`・`removeNote`、`showNotes`（表示だけ）、Selection に `note`、道具 `note`。`commit` の「変化なし」判定に `notes`、ネットワーク・器具が変わったら `syncNotes`。階を消したらその階のメモも消す。
- 画面: `src/ui/Notes.tsx`（編集欄・一覧）、`PlanView`（ピン・吹き出し・道具・ドラッグで移動）、`View3D`（札）、`Panels`（道具・選択の帯・表示）。

## テスト
- 単体: 位置合わせ（器具を動かす・区間を分ける・付けた先が消える）、番号、コピーの文字、保存と読み込み（notes 無しの古いデータも読める）、元に戻す。
- E2E（PC・iPhone・Android）: 道具で置いて書く → 図面にピン・一覧に出る → 器具を動かすとついてくる → 済にすると一覧の絞り込みから消える → 3D に札 → 削除・元に戻す。
