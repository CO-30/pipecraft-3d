# ⑥ 材料集計表 設計

ロードマップ ⑥（水匠NX申請の市町村様式の材料集計表、Rebro の工区ごとの拾い）。

## 目的
申請図面・施工の段取りで使う「材料表」を、配管データから自動で作る。積算の数量表は工事全体の合計だけなので、**分け方を選べる集計**にする。
- 分け方（列）: 「屋内・床下・屋外・地中」／「階ごと（床下・地中は別の列）」／「新設・既設」
- 区分（行のまとまり）: 給水・給湯／排水・通気（マスを含む）／その他（ガス・電気など）／器具
- 行: 管（管種・口径ごとの長さ m、実測優先）・継手などの部品（個）・器具（台）・マス（個）。各列と計

## 決定
- 区間は外壁の輪・各階の床・地面の高さをまたぐ所で分け、使用長を按分して、それぞれの中点の場所で決める: 建物（1 階の外壁の輪）の中で 1 階の床より下 → 床下、中 → 屋内、外で地面より下 → 地中、外 → 屋外。輪が閉じていなければ高さで分け（地面より下＝地中、床より下＝床下）、画面に注意
- 部品は積算の部品（nodeIds）の点の場所で数える。定尺の継ぎ足しは継ぎ目の場所。新設・既設は、つながる区間が全部既設の点だけ既設（既設の管に付けた新しい分岐のチーズは新設）
- 列が A4 縦に入らない（階が多い）ときは A4 横。仕様の列は 36mm 以上
- 長さは積算の使用長（実測優先）。計は積算の数量表と一致する
- 申請画面の新しい種類「材料表」（A4 縦、ページあふれは続き）。PDF・SVG。文字は表の枠の中（fitText）、noOverlap に追加
- 保存形式は変えない。分け方の選択は site.application の `zairyo.axis`
