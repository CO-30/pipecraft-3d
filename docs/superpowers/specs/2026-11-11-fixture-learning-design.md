# 器具の候補を、使う人の直し方から覚えて次回に合わせる — 設計（2026-11-11）

## 依頼
図面から自動で置いた浴槽が横向きだったが、実際は縦（左の壁沿い）だった。直したら次回からそれを覚えて精度を上げたい。
保存は**この端末だけ**（ユーザー決定。共有は必要になったら検討）。費用ゼロ・AI の画像認識は使わない。

## 方針
- 「部屋の名前」から出した候補（`source: 「UB」の部屋` など、位置は大まか）が対象。器具の名前の文字から出した候補（立水栓など）は今回は対象外。
- 部屋の名前の文字から上下左右に壁を探して**部屋の箱**（内法）を作る。箱の 4 辺 × 位置（壁の端 2 つ・真ん中。器具が辺いっぱいなら「いっぱい」1 つ）に、器具の奥を壁に付けた**置き場所（スロット）**を作る。
- 各スロットを、図面が変わっても通じる**特徴**で表す:
  - `wall`: その辺が 長い辺 / 短い辺 / ほぼ正方形
  - `door`: その辺と出入口（ドア）の関係 = 出入口の辺 / 向かい / 横 / 出入口不明
  - `pos`: 出入口に近い端 / 遠い端 / 真ん中 / 辺いっぱい / 端（出入口不明）
  - `label`: 部屋の名前の文字にいちばん近い辺か（今の置き方）
- **覚える**: 置いた候補の器具を使う人が動かす・回すと、いまの位置にいちばん近いスロット（同じ向きの軸、中心が 400mm 以内または箱の短辺の 1/4 以内）を探し、その特徴と「奥が壁側か反対か（flip）」を 1 件の記録にする（器具 1 個につき 1 件・上書き）。最初に置いたスロットへ戻した・スロットに当てはまらない所へ動かした・器具を消した ときは、その器具の記録を消す。
- **合わせる**: 次に図面を読んだとき、同じ種類の器具の記録（新しい順に最大 20 件）があれば、各スロットの点数 = Σ 記録ごとの特徴の一致（door 3・wall 2・pos 2・label 1、同じ部屋の名前 +1）で最高点のスロットに置く。同点は今の置き方（label の辺・真ん中）を優先。同じ部屋の先の器具と重なるスロットは使わない。記録が無い・部屋の箱を作れないときは今までどおり。
- 読み取り結果の画面: 合わせた候補は「（これまでの直し方 N 件に合わせた位置）」と表示。「向き・位置を直すと、この端末が覚えて次から合わせます」と「覚えた直し方を消す（N 件）」ボタン。
- 会社（図面の出どころ）ごとには分けない（図面から確実に見分けられないため）。特徴を出入口・辺の長さに対する関係で持つので、図面の向き・左右反転に左右されない。

## 作り（単位ごと）
- `src/model/planRead/roomSlots.ts`（純関数）: 部屋の箱、スロットと特徴の生成、位置からスロットを探す。
- `src/model/planRead/fixtureGuess.ts`: 部屋から出した候補に `room`（部屋の名前・スロット・最初に選んだスロット）を付ける。壁 `WallLine` に出入口の位置 `doors?: number[]`（a 端からの距離）を足す。位置・向きの決め方は変えない。
- `src/model/planRead/assemble.ts`: 壁の出入口（`type: 'door'` の開口部）を `doors` に入れて渡す。
- `src/learn/fixtureLearning.ts`（純関数）: 記録の型、スロットの点数付けと候補への適用 `applyLearned`、器具の位置から記録を作る `sampleFor`。
- `src/learn/learnStore.ts`: localStorage（`pipecraft3d.fixtureLearn.v1`）への読み書き。置いた器具の「見張り」（器具 id → 部屋の情報、最大 300 件）と記録（種類ごと最大 50 件）。共通ストアを購読し、見張り中の器具の位置・向き・有無が変わったら記録を作り直す。工事データには入れない。
- `src/state/store.ts`: `placeFixtureCandidates` が置いた器具の id を返す（置けなかったものは null）。
- `src/App.tsx` / `ImportReportDialog.tsx`: 読み取り後に `applyLearned`、置いたら見張りに登録、表示とボタン。

## テスト
- 単体: 部屋の箱・スロット・特徴（出入口あり/なし、辺いっぱい）、位置からのスロット探し（flip を含む）、点数付け（1 件の記録で次の図面の左右反転した浴室でも同じ特徴の辺に置く）、記録の作り直し（戻す・消す・当てはまらない）、localStorage が使えない環境。
- E2E（3 端末）: 図面を読み → 浴槽を回して別の壁へ動かす → もう一度読むと、その壁に置かれ「直し方 1 件」と出る。「覚えた直し方を消す」で元の置き方に戻る。

## 今回しないこと
- 図面に描かれた器具の輪郭（四角の線）から向きを読む改良（1 回目から効く）は、実物の図面で確かめる必要があるので別の作業にする。
- 器具の名前の文字から出した候補、端末間の共有。
