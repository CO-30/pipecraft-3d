# 外壁の写真から配管の長さを測る（2026-11-09 ユーザー要望）

## 要望
外壁の写真を撮って読み込み、屋上から地面まで通っている排水管などを指でなぞると、だいたいの配管の長さが出る。できればその写真を3Dの側面に貼る。

## 既にあるもの（変更しない）
- 立面図（`ElevationView`）: 外壁を正面から見た面。「📷 写真を敷く」で写真の四隅を壁の角に合わせて正面に補正（`PhotoRectify`・`homography.ts`）し、その上を指でなぞると壁の外側に配管ができる。区間ごとの長さを表示。
- 壁がない工事は「＋立面」で横幅・高さを入れて外壁を1枚作れる。

## 足りないもの → 今回の追加
1. **壁の一部で合わせる（基準の四角）**
   - 現場写真では壁全体が写らないこと（端が切れる、看板・木で隠れる）が多い。
   - 補正画面で「四隅は：壁全体／壁の一部（大きさの分かる四角）」を選べる。壁の一部の場合は 四角の横幅・高さ・壁の左端からの位置・下端の高さ（mm）を入れる（例: 窓1つ、1階床から4階床までの間）。
   - 四角の外も同じ射影変換で延長して、立面全体の画像を作る。写真の外は薄い灰色。
   - 基準の四角が壁からはみ出す・小さすぎる（100mm 未満）場合は補正しない。
2. **長さの合計**
   - 立面図の上部に「この面の配管 合計 ○.○m」（系統ごとの内訳つき）。
   - なぞっている間、指の位置に「約 ○.○m」。
3. **3Dの側面に写真を貼る**
   - 立面に写真があれば、3D でその外壁の表面（壁の外面から 3mm 外）に写真を貼る。配管は壁から浮いているので写真の手前に見える。
   - 外壁の表示（表示する・半透明・非表示）に従う。階で絞った表示では、その立面の階が見えるときだけ出す。断面で切る。タップは後ろの壁へ通す。
4. **入口: 新しい工事の作り方に「外壁の写真から測る」**
   - 階数・階高を入れて作成 → すぐ立面の作成画面（横幅・高さ・写真）を開く。高さの初期値 = 階数 × 階高。

## 精度・注意（画面と使い方に記載）
- 写真から測った長さは目安（四隅がしっかり写っていれば ±5〜10% 程度）。実測長があればそちらを優先（既存の仕組み）。
- 壁から手前・奥への出入りは写真では分からない。既存の「部材をよける」で補う。
- 写真は1面ごとに1枚。写真は工事データに保存（既存の容量上限に従う）。

## データ
保存形式の変更なし（`elevation.photo` は既存）。
