# 申請図面（排水縦断図・給水立面図）と自治体プロファイル 仕様（2026-11-09 合意）

plusCAD水道（水道設備工事業向け申請CAD）の「平面図から縦断図・立面図を自動作図する」機能を PipeCraft 3D に追加する。費用ゼロ（OSS・GitHub Pages のまま）。自治体差は **A. 自治体プロファイル方式** で吸収する。

リポジトリ接続後は本文を `docs/superpowers/specs/2026-11-09-shinsei-zumen-design.md` にコピーしてコミットし、writing-plans で実装計画を作る。

## 0. 目的・成功条件
- 目的: ユーザー自身の水道工事の申請業務で、PipeCraft 3D の配管データから排水設備の縦断図と給水装置の立面図（系統図）を自動で出し、自治体に提出できる体裁にする。
- 成功条件:
  1. 経路を選び自治体を選ぶだけで、勾配・管底高・累加距離・土被りの入った縦断図が PDF で出る。
  2. メーターから各水栓までの高さ・口径の入った立面図が PDF で出る。
  3. 自治体を増やすときコードを変えず、プロファイル（JSON）の追加だけで済む。
  4. 手計算で検証したテストケースと図面上の数値が一致する。
- 範囲外（今回やらない）: 申請書・数量表の Excel 様式差し込み（次段階 C 案）、本管図、管割図・日報、水理計算（流量・口径決定）。

## 1. データの追加（共通データ。2D・3D・積算は既存のまま使う）

### 1-1. 現場
- `designGL`（mm）: 設計地盤高。1階床面（FL±0）との高低差。GL が床より下なら負値。未入力は「仮」扱いで図面に「仮」表示。
- `municipalityProfileId`: 使用中の自治体プロファイル ID（既定 `standard`）。
- 将来拡張: ノードごとの地盤高 `groundLevel` で `designGL` を上書き（今回はフィールドだけ用意し UI は作らない）。

### 1-2. 器具「マス」の追加
- 種類: 汚水マス・雨水マス・トラップマス・インバートマス・公共マス（公共汚水マス／公共雨水マス）。
- 属性: 口径（既定 300）、形状（丸/角）、接続口 1 つ以上。接続口の高さ＝管底高。
- 深さ＝GL − 管底高 を自動表示（編集不可）。
- 3D は簡易形状（円筒/直方体）。2D は自治体プロファイルの記号で表示。
- 既存の器具接続口へつなぐ機能で、マスの接続口も始点・終点に使える。

### 1-3. 排水区間の勾配
- 排水・汚水・雨水の区間に `slope`（分母 n。1/n）と `slopeLocked`（真偽）を追加。
- 排水系では既存の高さ Z を **管底高** と定義する（他の種類は従来どおり）。
- 計算ルール:
  - `slopeLocked=true`: 上流端 Z と勾配から下流端 Z を再計算。
  - `slopeLocked=false`（既定）: 両端 Z から勾配を算出して表示。
  - 勾配を入力したら自動で `slopeLocked=true`。下流端 Z を手で動かしたら `slopeLocked=false` に戻す。
- 水平距離は 3D 座標の XY 距離。勾配＝(上流Z − 下流Z) / 水平距離。

### 1-4. 自治体プロファイル（JSON、Zod で検証）
```
{
  id, name, version, source（参照した手引き名・URL・確認日）,
  unverified: string[]  // 「要確認」項目名
  symbols: { [器具/マス/弁の種類]: SVGシンボルID }
  profileTable: {
    rows: [ { key: distance|cumDistance|groundLevel|invertLevel|cover|slope|pipeSpec|manhole, label } ]  // 順序どおり描く
    slopeFormat: 'ratio' | 'permille' | 'percent'  // 1/100・‰・%
    hScale, vScale                                  // 例 100, 50（1/100・1/50）
    minSlopeByDiameter: { [口径]: 分母 }             // 例 {75:50, 100:100, 150:150}
    minCover: number                                 // mm
  }
  riser: { lineStyle: 'single', diameterLabelPos: 'above'|'side', showFloorLines: boolean, heightLabel: 'FL+'|'GL+' }
  paper: { size: 'A3'|'A4', orientation: 'landscape'|'portrait', titleBlockFields: string[] }
}
```
- 同梱: `standard`（下水道協会方式を参考にした標準）1 件。個別自治体（那覇市・豊見城市など）は公開手引きを確認してから追加し、確認できなかった項目は `unverified` に入れて図面に「要確認」を表示する。
- ユーザーが追加・編集したプロファイルは IndexedDB に保存。同梱分は複製して編集する（同梱分は上書きしない）。
- 現場 JSON の書き出し/読み込みには、使用プロファイルの本体も同梱する（別端末で開いても同じ体裁になる）。

## 2. 排水縦断図

### 2-1. 経路の決定
- 「申請図面」タブで公共マス（または任意の下流端ノード）をタップ → 上流へ接続をたどって主経路を自動抽出。
- 分岐点では、ユーザーが枝を選ぶか「全部」を選ぶ。全部のときは主経路を図の本線、枝は折り畳んで接続点に「→別図/枝 n」と記し、枝ごとに別図を生成。
- 経路が閉路や未接続を含む場合はエラーを表示して生成しない。

### 2-2. 計算モデル（純粋関数）
`buildProfile(network, routeNodeIds, site, profile) → ProfileModel`
- ノードごと: 累加距離（水平距離の累計）、GL（`designGL`、将来 `groundLevel` 優先）、管底高、土被り＝GL − (管底高 + 外径)、マス種類・口径・深さ。
- 区間ごと: 水平距離、勾配（表記はプロファイルの形式に変換）、口径・管種。
- 警告: 最小勾配未満（`minSlopeByDiameter`）、逆勾配（下流が高い）、土被り不足（`minCover`）、GL 未入力（仮）。
- 単位は mm 内部計算、表示は m（小数 3 位）か mm をプロファイル／表示設定で切替。

### 2-3. 描画
`renderProfileSvg(model, profile) → SVG`
- 上段: 横軸＝累加距離（`hScale`）、縦軸＝高さ（`vScale`）。GL 線、管底線、マスを記号で描く。
- 下段: `profileTable.rows` の順で表を描く（各ノード/区間の列）。
- 警告箇所は赤で印を付け、欄外に一覧。
- 用紙枠・表題欄は `paper` に従う。

## 3. 給水立面図（系統図）

### 3-1. 経路の決定
- 起点: 水道メーター（なければ止水栓、なければユーザーが選ぶノード）。そこから給水・給湯の接続をたどって木構造を作る。給湯は給湯器を経由した枝として扱う。

### 3-2. 計算モデル（純粋関数）
`buildRiser(network, rootNodeId, building, profile) → RiserModel`
- 各ノードの階・高さ（FL 基準または GL 基準、プロファイルの `heightLabel`）、口径、器具・弁の種類。
- レイアウト: 本線を左、分岐は左から順に横へずらす簡易配置。階ごとの水平線を描く。

### 3-3. 描画
`renderRiserSvg(model, profile) → SVG`
- 単線。立ち上がり・横引きを直線で描き、口径を `diameterLabelPos` に、高さを「FL+○○」形式で記す。器具・弁はプロファイルの記号。

## 4. 画面・出力

### 4-1. 「申請図面」タブ（積算タブの隣）
1. 自治体プロファイル選択（現場の `municipalityProfileId`）
2. 図面種類（排水縦断図／給水立面図）
3. 経路選択（2-1 / 3-1）
4. プレビュー（ピンチズーム、スマホは全画面）
5. 出力: PDF（既存の PDF 生成を流用、用紙はプロファイル）、SVG 書き出し
- 配管・器具を編集すると積算と同様に自動で再生成。

### 4-2. 設定 > 自治体プロファイル
- 一覧（同梱／ユーザー）、複製、編集（項目ごとのフォーム。記号は同梱記号から選択）、JSON 読み込み/書き出し、削除（ユーザー分のみ、確認あり）。

### 4-3. 器具パネル
- マスの追加（種類・口径）、排水区間の勾配入力（テンキー、`1/` 固定表示）と「勾配固定」切替。

## 5. テスト
- 単体: 勾配↔管底高の再計算、累加距離、土被り、警告判定（最小勾配・逆勾配・土被り）、経路抽出（分岐・閉路・未接続）、立面図の木構造化、プロファイル Zod 検証。手計算ケース（直線 1 本、折れ 2 区間、分岐 1、2 階建て給水）と数値一致。
- スナップショット: `renderProfileSvg` / `renderRiserSvg` の SVG。
- E2E: サンプル工事にマスと排水経路を追加 → 縦断図 PDF 生成、給水立面図 PDF 生成（PC Chrome・スマホ縦・横の 3 端末）。
- 実機（ユーザー）: 自治体手引きの見本図と並べて目視確認。
- 後方互換: 旧データ（`slope`・`designGL`・マスなし）が開けて、縦断図は GL「仮」で生成できること。

## 6. 実装順（計画作成時の目安）
1. データ追加（1-1〜1-3）＋移行＋単体テスト
2. 自治体プロファイル（1-4）: 型・Zod・`standard`・保存・設定画面
3. 縦断図（2）: 計算→描画→タブ→PDF
4. 立面図（3）: 計算→描画→タブ→PDF
5. E2E・レビュー・PROGRESS 更新

## 7. 決定事項・注意
- 排水系の Z＝管底高。給水系は従来どおり（管中心）。
- 同梱プロファイルは `standard` のみ確定。個別自治体は手引き確認後に追加し、未確認は「要確認」表示（勝手に確定しない）。
- 本機能は作図支援であり、自治体の審査基準への適合を保証しない（既存の免責と同じ）。

### 実装時の決定（2026-11-09）
- 区間の `slope` は既存どおり **比率**（0.01 = 1/100）で保存する（既存の勾配機能・積算と互換）。画面とプロファイル表の表示だけ `1/n`・‰・% に変換。
- マスの接続口は中心 1 つ（流入・流出とも同じ管底高。落差は次段階）。管底高は `Fixture.params.invertZ`（絶対 mm、既定 GL−600）。
- 勾配固定の向き: 公共マスがあれば公共マスへ届く側が下流、無ければマスへ届く側、どちらでもなければ低いほう（同じ高さなら描いた向きの終点）。下流端がマスなら上流端を 管底高＋勾配×距離 に合わせ、マスの管底高を変えると固定区間の上流端が追従する。両端がマスの区間は上流マスの管底高を変える。
- 縦断図の経路は最上流のマスで切る（屋内の配管は含めない）。分岐の「全部」は本線＋枝ごとの別図を 1 つの PDF に。枝の中のさらに分岐は最長経路のみ。
- 描画は用紙 mm 座標の命令列（`Sheet`）を SVG（プレビュー）と pdf-lib（PDF）の両方に変換する。PDF では多角形の塗りつぶしを省略（輪郭のみ）。
- 設定画面はホームではなく申請図面画面内の「⚙ プロファイルを管理」から開く。
- `groundLevel` はノードのフィールドと計算だけ用意（UI なし）。
