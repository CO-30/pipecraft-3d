# 申請書類の自動作成（沖縄市）— 設計（2026-11-10）

## 目的
申請担当者から入手した沖縄市の様式に、現場データ（配管・マス・器具・積算）と申請情報を差し込み、提出できる形で出力する。
- 給水装置申込及び工事申請書（Excel 様式 → .xlsx で出力）
- 下水道排水設備計画確認申請書（様式第1号、PDF → 1 面に文字を重ね、2 面「平面図及び縦断面図」に縦断図、3 面「配管立図」に排水の立面図（展開図）を縮小して載せる。4 面「見取図」は空欄）
- 給水装置使用製品一覧表（A4 横。積算の管・部品から自動で行を作る。発行元の企業団は要確認）
- 提出書類チェックシート（給水申請チェックシートの項目を画面に表示。アプリで作れるものには印）

## 入力
- 申請情報 `doc.application`（現場ごと。全て省略可の文字列の辞書 `Record<string,string>`。`SCHEMA_VERSION` 据え置き）
  - 様式の項目は `src/forms/okinawaCity.ts` の `FormField[]` で定義（id, label, kind: text|choice|number|date, options, group, hint）。画面はこの定義から自動生成
  - 既定値は現場から導く: 設置場所 ← 現場名/住所、メーター口径 ← 水道メーター器具の口径、世帯数 1、工事種別 新築 など
- 工事店情報（端末ごと、IndexedDB `settings` テーブル key `contractor`）: 商号、交付番号（沖水第 n 号）、〒・住所、代表者、電話、主任技術者、排水設備工事責任技術者と登録番号
  - 公開リポジトリには実データを入れない。様式のテンプレートは記入例の値を全て空にして同梱（`public/forms/okinawa-city/`）

## 出力の作り方
- Excel: ExcelJS でテンプレート（LibreOffice で xls→xlsx 変換、画像と記入例を除去、18KB）を読み、セルに値を書く。選択肢（新設/改造、使用形態 1〜8 など）は該当の番号を ①② の丸数字に置き換え、有/無は「○有」のように前に ○ を付ける
- PDF: pdf-lib で様式 PDF を読み込み、1 面に NotoSansJP で文字を描く（座標は `pdftotext -bbox` で取得、pt）。選択肢は番号の周りに円。2・3 面は `drawSheetOnPage(page, font, sheet, box)` で既存の `Sheet` を縮小して描く
- 製品一覧表: `Sheet` で A4 横に表を描く（既存の sheetsToPdf）
- 他の自治体: 様式が未登録のときは画面にその旨を出し、申請情報の入力だけできる

## 決定
- 手数料（加入金 13mm 12,650 円・20mm 32,450 円、設計審査 160 円、検査 980 円）は実例 2 件の値を既定として入れるが「要確認」と表示する
- 丸囲みの代わりに丸数字を使う（Excel で図形を描くより壊れにくい）
- 見取り図・建物側面図の欄（Excel 裏面・1 面下部）への画像貼付は今回は行わない（次段階）
- 落差桝・ヘッダー工法（給水ヘッダー）は未対応のまま（PROGRESS に記録）
