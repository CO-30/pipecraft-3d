# ⑧ 系統をたどって強調 — 設計（2026-11-12）

元: Rebro の「系統選択」。配管を 1 本選んで、同じ系統につながる管・器具をまとめて強調し、長さ・口径別・器具数を出す。

## 決めたこと
- たどる範囲: 選んだ区間と同じ種類の管がつながる所すべて。汚水（sewage）と雑排水（drain）は 1 つの排水系統として続ける。通気・給水・給湯・ガスなどは種類が変わる所で止める
- 器具の扱い: 器具に届いたら、その器具の別の接続口のうち同じ系統の口から先へ続ける（メーター・ポンプ・屋上タンク・ヘッダー・マスを通り抜ける）。給湯器は給水と給湯で系統が変わるので止まる。届いた器具は強調に入れる
- 長さ: 実測があれば実測（材料表・積算と同じ）。口径ごとの長さ、器具の数、バルブの数
- 状態: 画面だけの状態 `trace`（出発の区間 ID）。図面データ・元に戻すには入れない。図面が変わるたびに出発の区間からたどり直す。出発の区間が消えたら強調も消える。工事を開く・閉じるときに消す
- 画面:
  - 区間の詳細に「🔗 この系統をたどる」。器具の詳細には、つながっている系統ごとに「🔗 給水をたどる」など
  - 強調中は上に帯「系統: 給水 — 管 12.3m（φ20 8.1m・φ13 4.2m）・器具 5・バルブ 1 ［✕ 強調をやめる］」
  - 2D: 系統の管に選択色の太い縁、ほかの管と器具は薄く。3D: 系統の外の管・器具を半透明に、系統の管を光らせる
- 触らないもの: 排水チャットとの約束のファイル（network.ts など）は読むだけ

## テスト
- 単体（`src/model/trace.test.ts`）: 種類が変わる所で止まる・汚水と雑排水は続く・ヘッダー/メーターを通り抜ける・給湯器で止まる・実測優先の長さと口径別・バルブの数・無い区間は null
- E2E（`e2e/trace.spec.ts`）: サンプル工事で区間を選び「系統をたどる」→ 帯に長さ・器具数、2D の強調、やめると消える（PC・iPhone・Android）
