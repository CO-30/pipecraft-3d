# ⑩ 保存した版との比較 — 設計（2026-11-12）

有料 CAD の取り込み計画の ⑩（Rebro の「図面の比較」）。

## 目的
- 「申請を出した時」「施主に見せた時」などの状態を **版** として残し、今と比べて **何が増えた・減った・変わったか** を図面で一目で分かるようにする（変更申請・追加工事の説明・見積の出し直し）。
- 間違えて大きく変えたときに、版へ戻せる。

## 決めたこと（ユーザーに聞かずに判断）
- **版を残す**: 表示パネルの「🕘 版」→「＋ 今の状態を版にする」（名前は既定で日時。「申請提出」などに直せる）。工事ごとに 20 版まで（あふれたら古いものから消すと知らせる）。端末の中（IndexedDB の別の表）に保存。工事を消すと版も消える。
- **比べる**: 版の「比べる」で比較の表示に入る（画面だけの状態。元に戻すには入れない）。
  - 2D: 増えた管・器具は緑の縁、なくなった管・器具は赤の破線（版のときの形を重ねる）、口径・材料・種類が変わった管はだいだいの縁、動いた器具は版の位置を灰の破線＋今の位置にだいだいの縁。ほかは薄く。
  - 3D: 増えた管を緑に光らせ、なくなった管を赤の半透明で重ねる。
  - 図の下に帯: 比べている版の名前・日時、増えた／なくなった／変わった数（配管・器具）、系統ごとの管の長さの差（実測優先・割増なし）。「一覧」で変わった所の一覧（タップでその階へ移って選ぶ）。「✕ 比較をやめる」。
- **同じ管の見分け**: 区間の ID ではなく形で比べる（バルブ・分岐で区間を分けても「変わっていない」）。同じ種類の管の上に両端が乗っていれば同じ管。両端が同じで口径・材料・種類が違えば「変わった」。器具は ID で（位置・向き・種類）。
- **戻す**: 版の「戻す」→ もう一度押して確定。戻す前の状態を自動で版に残し（「戻す前 日時」）、戻す操作は元に戻すで取り消せる。
- 建物（壁・部屋）の違いは数だけ帯に出す（「建物も変わっています」）。
- 版は工事の書き出し（JSON）には入れない（端末の中だけ）。

## 部品
- `src/model/compare.ts`（純粋な関数・単体テスト）: `compareDocs(old, now)` → 管の増減・変更、器具の増減・移動・変更、系統ごとの長さの差、建物の数の差。
- `src/storage/repository.ts`: Dexie version 4 に `versions` 表（id, projectId, createdAt）。`saveVersion`・`listVersions`・`loadVersion`・`deleteVersion`。工事を消すと版も消す。
- `src/state/store.ts`: `compare`（比べている版の Doc と名前。画面だけ）、`setCompare`、`restoreDoc`（版の中身で commit）。
- 画面: `src/ui/Versions.tsx`（版の一覧・比べる・戻す・消す、比較の帯と一覧）、`PlanView`・`View3D` の重ね描き。

## テスト
- 単体: 形で比べる（区間を分けても同じ・口径が変わった・増えた・なくなった・器具の移動）、長さの差、版の保存・一覧・読み込み・20 版を超えたら古いものを消す・工事を消すと版も消える、戻す（元に戻すで取り消せる）。
- E2E（PC・iPhone・Android）: 版を残す → 管を足して器具を動かす → 比べる（帯の数・2D の色）→ 3D → 戻す → 元に戻す。

## 見送り
- 別の端末と版を共有、版どうしの比較（今との比較だけ）、申請図面（PDF）の上での比較、建物の線ごとの比較。
